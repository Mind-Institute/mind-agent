# Instruções para coding agents

Este arquivo é um **ponteiro**, não uma segunda constituição.

1. Leia **[`CLAUDE.md`](CLAUDE.md)** — regras de trabalho, versionamento de decisões e ordem de autoridade.
2. Leia **[`PROJECT_STATE.md`](PROJECT_STATE.md)** — arquitetura congelada, roadmap, ordem de execução e checkpoint atual.
3. Leia **[`BACKLOG.md`](BACKLOG.md)** — investigações/fragilidades deferidas que não devem ser refeitas do zero.
4. Leia **[`docs/CORE_UNIVERSAL.md`](docs/CORE_UNIVERSAL.md)** — estado real e contratos já implementados.
5. **Investigue o sistema real** (Supabase, código, migrations aplicadas) antes de alterar qualquer coisa. Documentação descreve o sistema; não substitui verificá-lo.
6. **Documentação antiga não é autoridade.** Se um documento contradiz o sistema vigente, o sistema vence e a documentação deve ser reconciliada. Decisão congelada nova não pode ficar só em conversa.
7. **Siga o menor passo correto.** Implemente o que foi pedido, não o que seria elegante.
