# Instruções para coding agents

Este arquivo é um **ponteiro**, não uma segunda constituição.

1. Leia **[`CLAUDE.md`](CLAUDE.md)** — regras de trabalho e ordem de autoridade.
2. Leia **[`docs/CORE_UNIVERSAL.md`](docs/CORE_UNIVERSAL.md)** — o documento canônico do sistema.
3. **Investigue o sistema real** (Supabase, código, migrations aplicadas) antes de alterar
   qualquer coisa. Documentação descreve o sistema; não substitui verificá-lo.
4. **Documentação antiga não é autoridade.** Se um documento contradiz o sistema vigente, o
   sistema vence.
5. **Siga o menor passo correto.** Implemente o que foi pedido, não o que seria elegante.
